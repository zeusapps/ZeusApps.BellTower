## Findings

### QA-100: `doctor` `vsCode` property changed from a string to an object (undocumented contract change)

- Severity: suggestion
- Related task / requirement: 5.2
- Location: `src/BellTower/Diagnostics/DiagnosticsReporter.cs:38`
- Expected / actual: previously `vsCode` was the string `"requires bundled focus bridge"`; it is now an object (`bridge`, `states`, `windows`, `sessions`). A repo-wide search (tests, scripts, docs, psm1, vscode, excluding `docs/handoffs`) found no consumer reading the old value, and `CliTests` doctor tests pass, so nothing in the repository breaks. External scripts parsing the old string would. The `Windows`/`Sessions` fields can also be the string `"unavailable: registrations could not be read"` (type varies).
- Reproduction: `grep -rn "requires bundled focus bridge"` shows only the reporter constant.
- Evidence: source inspection plus full suite pass.
- Recommended correction: note the shape change in the docs/changelog for `doctor`, and optionally keep the field type stable (empty list plus an `error` field).
- Relationship: new, related to QA-004 (which is otherwise verified)
