### QA-1100: Non-elevation of the restarted backend, launching shell and observer has no retained raw record

- Severity: warning
- Related task / requirement: 1.2 to 1.3; analysis-006 probe plan (non-elevated TUIs)
- Location: `evidence/native-adoption-011.md` line 14 (elevation sentence); raw: `artifacts/native-adoption-011/run/*.elevation.json`
- Expected / actual: the evidence states a process-token query for the launching PowerShell session and the restarted backend (both 0). Retained data contains token records only for clients A, B, C and D (`ctl.ps1` line 46). No file, script output or log records a token query for the shell, the second backend (PID 42432) or the observer processes. The first backend is honestly marked unqueried.
- Reproduction: `Select-String -Pattern 'elevat'` over every retained text file under `artifacts/native-adoption-011` returns only `ctl.ps1` and the four `run/*.elevation.json`.
- Evidence: the claim is plausible (both processes descend from non-elevated parents, and an unelevated parent cannot start an elevated child), but it is not verifiable from retained data, and the same inheritance argument applies equally to the first backend, which the evidence treats as unqueried.
- Recommended correction: state which processes were token-queried (A to D) and that the shell and second backend claims rest on inheritance, or note the query output was not retained. Optionally record the output in future probes.
