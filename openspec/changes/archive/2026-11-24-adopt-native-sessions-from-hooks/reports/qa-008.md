## Findings

### QA-700: Evidence does not record an outbound request to a remote ChatGPT endpoint during the run

- Severity: warning
- Related task / requirement: 1.1 (probe records of what is actually verified); assignment check 3
- Location: `openspec/changes/adopt-native-sessions-from-hooks/evidence/codex-headless-004.md` (stage table and Execution context); raw trace `artifacts/codex-headless-004/stderr.log` at 446 ms
- Expected / actual: A run described as using a closed loopback model endpoint and a dummy credential should state what other network access occurred. The trace shows Codex made a startup request to a remote ChatGPT backend path (featured-plugin cache warm-up) that returned 401 Unauthorized. The evidence says only "no catalog network access", which omits it. The "no network beyond loopback" property cannot be asserted from this run.
- Reproduction: `Select-String -Path artifacts\codex-headless-004\stderr.log -Pattern 'plugins/featured'`
- Evidence: single trace line at 446 ms, status 401; no other non-loopback URLs in the trace. No socket-level capture was taken, so other traffic cannot be excluded.
- Recommended correction: Add one sentence to the evidence file stating that the headless run attempted an unauthenticated remote plugin-metadata request that failed with 401 and that the path was non-blocking and unrelated to hook dispatch. Do not claim loopback-only. If isolation is wanted, document disabling that feature for the probe or note the limitation.
- Relationship: none

### QA-701: Hook-before-model-request ordering is inferred, not logged

- Severity: suggestion
- Related task / requirement: 1.1
- Location: `evidence/codex-headless-004.md` stage table row "about 2.08 s | SessionStart hook executed"
- Expected / actual: The row reads as a Codex-observed hook stage. The trace contains no hook-dispatch line; the time is the handler's own capture timestamp compared with trace timestamps. The ordering conclusion holds (40.42 vs first request 42.56), but the source of the stage time should be named.

- Evidence: described above.
- Recommended correction: Note that the hook stage time comes from the capture's timestamp.
- Relationship: none
