## Assessment and limitations

QA-4800’s concrete coverage gap is corrected: the new tests exercise the production CLI action and the production tray Exit click handler, with disposable paths and no real tray start. Provider parity for the shared ingress is represented by matched Claude/Codex fixture rows, including mixed concurrency and the breakaway-refusal case.

ANALYSIS-4100 is improved for split-token UAC sessions: Full-token hooks select the linked Limited token for the user-stop identity and launch through that limited token. The remaining Default-token path is unresolved because the code infers non-elevation from absence of a linked token. The real elevation-pair requirement remains open.

ANALYSIS-4101’s unsafe retry inside a job is removed and the synthetic refusal branch is covered. The “outside the provider’s job” acceptance remains unproven for a successful breakaway under nested jobs, because the implementation does not check the created process against all job membership, and no actual Codex hook job was tested. Keep the native Codex job and installed host trials open.

No build, formatter, live provider session, or native elevation/job trial was run in this QA round. The focused test result above was supplied by the orchestrator; no second test run was started while the root full-suite request was active. No source, tests, user configuration, process state or other report was modified by QA.
