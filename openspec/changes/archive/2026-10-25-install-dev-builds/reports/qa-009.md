## Findings

### QA-450: Whole-solution format verify fails on an LF test file

- Severity: warning
- Related task / requirement: 4.1 (format gate in `docs/development.md`)
- Location: `tests/BellTower.Tests/Scripts/InstallDevScriptTests.Recovery.cs`, whole file (519 lines), at `b74a12b` plus working tree, modified 11:46 local
- Expected / actual: Expected `.editorconfig` `end_of_line = crlf`, so format verify passes. Actual: the file has LF endings and `./scripts/format.ps1 -Verify` exits 1 with 519 ENDOFLINE errors, all in this file. The implementation handoff reported a passing scoped verify, so the file was probably rewritten after that check.
- Reproduction: `pwsh ./scripts/format.ps1 -Verify` from the repository root.
- Evidence: [qa-009-format.txt](../evidence/qa-009-format.txt), [rerun](../evidence/qa-009-format-rerun.txt). A byte check shows no CR in the file.
- Recommended correction: the developer converts the file to CRLF with `dotnet format ZeusApps.BellTower.slnx --no-restore --include tests/BellTower.Tests/Scripts/InstallDevScriptTests.Recovery.cs`, then reruns `./scripts/format.ps1 -Verify`. A line-ending-only change: no behavior risk.
- Relationship: new
