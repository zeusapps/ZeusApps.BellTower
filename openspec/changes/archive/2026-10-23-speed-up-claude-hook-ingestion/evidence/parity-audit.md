# Fast ingress parity audit

Scope: Windows x64 local Claude Code and Codex integrations. Shared product policy lives in the capture protocol, consumer, reducers, identity observer and structural setup ownership. Provider adapters choose event names, shell syntax and transport fields. This feature does not change existing native-name, runtime-token or presentation ownership rules.

| Control/behavior | Claude | Codex | Evidence |
| --- | --- | --- | --- |
| Native durable capture, byte/BOM bounds and neutral output | Same protocol/default | Same protocol/default | Source-generated round trips, executable and malformed/oversized input tests |
| Capture while tray/state locks are unavailable | Available | Available | 64 parallel writes while state/identity locks are held; stopped-tray and packaged lifecycle trials |
| Bounded consumer, crash replay, legacy inbox | Shared | Shared | Commit-failure retention, commit-before-delete replay, bounded backlog and mixed fixtures |
| Causal turns, operation completion, ended attachment and resume | Shared | Shared | Shuffled replay, result-before-start, late startup rejection and explicit resume cases |

| Async/default timeout control | Regular capture async, timeout 3 | Regular capture async, timeout 3 | Structural setup fixtures and current provider contracts; SessionEnd synchronous for both |

| Shared/remote runtime ownership | Existing ownership checks retained | Explicitly unverified attachment when no dedicated ownership evidence exists; no token copied into captures | Existing provider/runtime/name/permission tests plus packaged fake-runtime trial |

The transcript exception is confined to reconstructing complete retrospective counts from the specific Codex chat history. Capture health and native hook status remain the honest shared fallback. Other provider versions/modes are not labelled proven restricted. No missing implementation is reclassified as a platform limitation.

The first packaged benchmark retained 121 native samples for each provider, 242 durable captures, eight independent conversations and all completion times below three seconds. The mixed lifecycle trial preserved a live disposable provider/backend through selected-version changes and compatible rollback; it retained old immutable images while installing a new image.

Authenticated provider tool runs, native human approvals and the actual RDP field-machine timeout rate remain release-field acceptance work. They are not reported as passed here and are not treated as provider restrictions. This implementation's required isolated fixtures, installed-shell performance and update/rollback coverage are separate evidence. Final build/test/package results are recorded in the implementation verification note.
