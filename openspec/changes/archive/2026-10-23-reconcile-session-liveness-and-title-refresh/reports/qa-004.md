The actual historical launcher lacks new health guards, so independently starting it on migrated state remains unsafe; the tested recipe restores compatible state first. Concurrent setup/version changes or owner/selection conflicts must be handled by refusal/inspection, not forced continuation.

The actual live C: installation/data and D: private backup were not opened or modified by QA. Cross-volume backup uses copies, while restoration uses a same-target-directory temporary replacement; no recursive move/delete is involved.
