## Assessment and limitations

- Every spec scenario is met for Claude Code, Codex and mixed state by executed fixture tests: compaction after settling, delayed earlier event after compaction, resume after compaction (including events of the resumed session delivered before its registration), many ended sessions, recovery at the budget, live-only overflow, doctor state section. Tasks 1.1-1.5 and 2.1-2.3 are met. Tasks 3.1 (this QA round and the analyzer's recheck are pending for 3.2; `openspec validate --strict` was not part of this assignment) and 3.3 (installed check) were not assessed. The orchestrator's [field-recovery probe](../evidence/field-recovery-001.md) is separate evidence and was not re-run.
- The new fold rule behaves as designed: compaction folds only observations at or before the session's last applied observation, the floor never moves backward, strays are kept against a checkpoint copied from the compacted session, a late resume sorts ahead of them, delayed earlier events stay ignored, and repeated strays neither grow the journal past the window nor cause a save loop.
- Residual sanitizer behavior, not a finding: when the last path segment under a masked root contains a space, the words after the first space can remain (for example `"<path> b.txt"` or `'<path> y'`). They are file-name words, never the profile, user name, root or directory. This is the same residual that [qa-002](qa-002.md) recorded and the design accepts (bounded message, exception type kept).
- Documented design limits, not defects: an observation with the same `At` as the last applied one but a later kind is folded with the session; compaction in an over-budget backlog drain gives up the backlog protection for that drain.
- Not performed: the installed check (3.3), the real tray, the real data directory and `TrayApplication` execution.
- Unexpected writes: none to the repository. This report is the only file written under the change root. Scratch files were outside the repository.
